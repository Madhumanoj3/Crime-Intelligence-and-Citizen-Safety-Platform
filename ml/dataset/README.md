# SYNTHETIC DATA — not real incidents

Every record in this folder is **synthetic**. The records were generated by `ml/generate_datasets.py` (fixed seed, so reruns give the same output). They do not describe real crimes, real complaints or real people. Every ID starts with `SYN-`.

| File | Rows | Used by |
|---|---|---|
| `crime_hotspot_dataset.csv` | 1,000 | Crime Hotspot Analysis (DBSCAN) and the dashboard map |
| `complaint_similarity_dataset.csv` | 1,000 | Complaint Similarity (TF-IDF + cosine similarity) |
| `complaint_similarity_groundtruth.csv` | 1,000 | Evaluation only: maps each complaint to its incident group |

Coordinates are placed around real Tamil Nadu localities, as listed in `ml/tn_localities.py`. Shop and street names in the complaint text are invented.

Regenerate: `python ml/generate_datasets.py`. Validate: `python ml/validate_datasets.py`.
